Engineering questions & Socratic vision

Discuss these with your team after building. There is no hidden answer or single correct architecture; use your artifact and evidence to defend your choice.

  1. Why is response.ok necessary after fetch resolves?
  2. When are retries safe for a profile GET?
  3. What is lost if every provider error becomes invalid credentials?
  4. Which endpoint configuration could create a server-side request forgery?
  5. Why should a response size limit be independent of the request limit?
  6. How would you test a timeout without making the suite slow?
