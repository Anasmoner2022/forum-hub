Full specification

Required behavior

  1. Call a configured, allowlisted provider profile endpoint with Node fetch; send server-side credentials only to that provider.
  2. Use AbortSignal.timeout, check response.ok, bound response bytes to 256 KiB while streaming, and validate parsed response fields.
  3. The local fake provider exposes /profile, /slow, /bad-json and /unavailable; this lab owns these endpoints and uses only synthetic credentials.
  4. Map provider errors to controlled domain failures. Do not log authorization headers, tokens or full callback URLs.
  5. Inject fetch and endpoint configuration for deterministic tests; do not automatically retry authorization-code exchanges in later projects.

Out of scope

Build this focused deliverable, not the complete forum. Features in the Level up chapter are optional and are not prerequisites unless the roadmap explicitly selects them. Do not replace a core learning task with a framework or finished service.

Use synthetic users and disposable test data during development. Keep a decision record when the brief allows a choice; the record must include an independently verifiable consequence.
