Overview

Connect a tiny account application to both Google and GitHub and map verified provider identities to local members without email-based takeover.

Concrete deliverables

  • Two live provider adapters plus deterministic synthetic tests
  • A provider setup worksheet, identity schema and explicit link flow

Why build this?

The learner must make both providers observable and defend the failure case “Link conflict”. Reading alone does not prove those behaviors; the artifact and review evidence do.

Prerequisites

  • P14: OAuth Authorization Code, State and PKCE Lab
  • P09: Registration and Password Hashing Vault

Reuse and what changes

  • P14: OAuth Authorization Code, State and PKCE Lab supplies tested contracts. Preserve those behaviors while building Google OIDC, GitHub Identity and Account Linking.
  • P09: Registration and Password Hashing Vault supplies tested contracts. Preserve those behaviors while building Google OIDC, GitHub Identity and Account Linking.

Time and team

Estimated 14 focused learner-hours, including reading, implementation and review. Each learner builds and explains the core; pairing and review are encouraged.
