Overview

Build a feed query engine that combines label filters with the authenticated member’s created and liked topics without duplicating cards.

Concrete deliverables

  • A feed query module with deterministic pagination
  • A hand-calculated fixture proving ownership and counts

Why build this?

The learner must make label observable and defend the failure case “Counts”. Reading alone does not prove those behaviors; the artifact and review evidence do.

Prerequisites

  • P07: Reaction State Machine and Transactions

Reuse and what changes

  • P07: Reaction State Machine and Transactions supplies tested contracts. Preserve those behaviors while building Feed Filters, Aggregates and Pagination.

Time and team

Estimated 10 focused learner-hours, including reading, implementation and review. Each learner builds and explains the core; pairing and review are encouraged.
