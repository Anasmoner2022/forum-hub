Step 2: Persist and replace

Mount storage, set file ownership and demonstrate container replacement.

Questions before writing

  1. Which input and trusted context enter this component of Docker Images, Volumes and Restore Drill?
  2. Which persisted or visible invariant must remain true if this step fails?
  3. A mount can hide directories created in the image.

Guided build

  1. Write a small acceptance example for persist and replace using this project's verification table.
  2. A mount can hide directories created in the image.
  3. Remove containers only after recording which named volume holds the test data.
  4. Implement the smallest boundary that satisfies that example; keep core logic in your own module and record your chosen policy.

Self-check

Create a topic, replace the container and read the same topic ID.

Evidence to keep

Keep the exact input, observed result and state/diagram evidence that make this self-check independently reviewable. If the result differs, trace the component before continuing.
