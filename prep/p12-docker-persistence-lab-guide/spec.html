Full specification

Required behavior

  1. Use a Node 24.15+ Debian-based image pinned to a cohort-approved patch/digest; install locked dependencies inside the image with npm ci, never copy host node_modules.
  2. Run as a non-root user with explicit writable data and upload directories; expose the documented app port and bind the server to 0.0.0.0 in the container.
  3. Persist the whole SQLite directory in a named volume, including WAL/SHM companion files when WAL is used; replace the container without losing data.
  4. Build .dockerignore excluding secrets, private certificates, databases, node_modules and irrelevant academy guide files. Record supported host/container architectures.
  5. Practise a consistent backup using SQLite backup API or a stopped/closed database copy. Restore to a separate disposable location, verify migrations, foreign keys and row counts, and keep live data intact.

Out of scope

Build this focused deliverable, not the complete forum. Features in the Level up chapter are optional and are not prerequisites unless the roadmap explicitly selects them. Do not replace a core learning task with a framework or finished service.

Use synthetic users and disposable test data during development. Keep a decision record when the brief allows a choice; the record must include an independently verifiable consequence.
