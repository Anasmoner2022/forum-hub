Step 1: Build a reproducible image

Write the image recipe and ignore policy using the tested mini board.

Questions before writing

  1. Which input and trusted context enter this component of Docker Images, Volumes and Restore Drill?
  2. Which persisted or visible invariant must remain true if this step fails?
  3. Pin a reviewed runtime digest at cohort release.

Guided build

  1. Write a small acceptance example for build a reproducible image using this project's verification table.
  2. Pin a reviewed runtime digest at cohort release.
  3. Install dependencies in the target container rather than carrying them from Windows.
  4. Implement the smallest boundary that satisfies that example; keep core logic in your own module and record your chosen policy.

Self-check

A clean Docker build does not depend on local node_modules or an existing database.

Evidence to keep

Keep the exact input, observed result and state/diagram evidence that make this self-check independently reviewable. If the result differs, trace the component before continuing.
