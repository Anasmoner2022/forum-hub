Before implementing anything, predict the “Cipher engine” case: input query cipher_version in clean Linux image, result nonempty supported cipher version. Then contrast it with “Rotation/recovery”.

Keep the boundary visible

  • openEncryptedDatabase(path, secretPath): Verify driver, load fixed-size key and confirm schema access.
  • exportEncryptedCopy(source, targetPath, targetKey): Export to a separate encrypted database and verify metadata/counts.
  • rotateDatabaseKey(db, newKey): Perform a documented disposable rekey and verify both old/new behavior.

The short example illustrates an API or a reasoning tool. It does not implement the required service. Return to the mandatory reading if you cannot explain the example’s inputs, side effects or possible errors.
