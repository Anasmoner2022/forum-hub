Step 1: Build and verify the encrypted driver

Use a cohort-pinned Linux build with build-essential, libssl-dev and pkg-config for source compilation; retain required runtime libcrypto.

Questions before writing

  1. Which input and trusted context enter this component of Optional Live Database Encryption and Recovery Lab?
  2. Which persisted or visible invariant must remain true if this step fails?
  3. Install native dependencies in the target image and keep package-lock.json.

Guided build

  1. Write a small acceptance example for build and verify the encrypted driver using this project's verification table.
  2. Install native dependencies in the target image and keep package-lock.json.
  3. Treat Windows as a Docker host; the binding runs inside Linux.
  4. Implement the smallest boundary that satisfies that example; keep core logic in your own module and record your chosen policy.

Self-check

The clean container reports a nonempty cipher_version and passes a create/insert/select contract test.

Evidence to keep

Keep the exact input, observed result and state/diagram evidence that make this self-check independently reviewable. If the result differs, trace the component before continuing.
