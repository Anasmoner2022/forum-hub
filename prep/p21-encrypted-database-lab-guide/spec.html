Full specification

Required behavior

  1. This is optional preparation for live database encryption. node:sqlite is ordinary SQLite; setting PRAGMA key there does not add encryption. Use the reviewed @journeyapps/sqlcipher driver in a Linux container, not an assumed Windows native install.
  2. The driver is callback-based and source-built. Teach its run/get/all/prepare/finalize/close APIs, awaitable wrappers, serialized transactions and OpenSSL/native toolchain dependencies before adapting the P06/P07 repository.
  3. Load a random 32-byte raw key from an operator-mounted secret file; use the documented SQLCipher raw-key syntax with strictly hex-encoded bytes before the first database read. Never concatenate an arbitrary passphrase into SQL.
  4. Prove PRAGMA cipher_version is nonempty and query schema immediately after keying to force verification. Missing/wrong keys and ordinary SQLite readers cannot read the protected database.
  5. Export a consistent disposable plaintext fixture into a separately keyed database using sqlcipher_export and preserve schema version metadata explicitly; compare every table count and all repository contract tests before discarding any copy.
  6. Use cipher_integrity_check and ordinary integrity/foreign-key checks, rehearse PRAGMA rekey on a disposable copy and prove old key fails while new key works. Backups remain encrypted or are protected separately; keys stay out of repository, logs, command arguments and image layers.
  7. Supply an encrypted-copy restore drill and a key-loss/rotation ownership procedure. Encryption at rest does not protect data from an authorized running process or replace password hashing.

Out of scope

Build this focused deliverable, not the complete forum. Features in the Level up chapter are optional and are not prerequisites unless the roadmap explicitly selects them. Do not replace a core learning task with a framework or finished service.

Use synthetic users and disposable test data during development. Keep a decision record when the brief allows a choice; the record must include an independently verifiable consequence.
