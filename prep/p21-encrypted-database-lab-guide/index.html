P21: Optional Live Database Encryption and Recovery Lab

Build a Linux-container SQLCipher repository adapter, migrate a disposable plaintext database into encrypted storage, and rehearse key rotation and recovery before choosing the source encryption bonus.

This is a hands-on build guide with a complete specification, an unfinished scaffold, guided component steps and verification. The student supplies the implementation or design.
