Overview

Build a Linux-container SQLCipher repository adapter, migrate a disposable plaintext database into encrypted storage, and rehearse key rotation and recovery before choosing the source encryption bonus.

Concrete deliverables

  • A real encrypted SQLCipher database and equivalent repository contract tests
  • A reproducible native-driver Docker build, key procedure and verified recovery drill

Why build this?

The learner must make cipher engine observable and defend the failure case “Rotation/recovery”. Reading alone does not prove those behaviors; the artifact and review evidence do.

Prerequisites

  • P12: Docker Images, Volumes and Restore Drill
  • P20: Session Attack and Browser Defense Workbench

Reuse and what changes

  • P12: Docker Images, Volumes and Restore Drill supplies tested contracts. Preserve those behaviors while building Optional Live Database Encryption and Recovery Lab.
  • P20: Session Attack and Browser Defense Workbench supplies tested contracts. Preserve those behaviors while building Optional Live Database Encryption and Recovery Lab.

Time and team

Estimated 16 focused learner-hours, including reading, implementation and review. Each learner builds and explains the core; pairing and review are encouraged. This project is optional and required only if the database-encryption bonus is selected.
