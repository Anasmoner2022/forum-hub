Full specification

Required behavior

  1. GET /health returns 200 application/json with {"ok":true}. POST /echo accepts application/json and returns the parsed object with status 200.
  2. Unknown paths return 404; a known path with an unsupported method returns 405 and Allow; unsupported body type returns 415; malformed JSON returns 400.
  3. Limit request bodies to 65536 bytes measured as bytes, including chunked requests with no Content-Length; overflow returns 413.
  4. Bound the time spent receiving a body, handle aborts and stream errors, and never send two responses.
  5. Use URL for pathname/query parsing; return a generic 500 on unexpected errors and keep the process available.
