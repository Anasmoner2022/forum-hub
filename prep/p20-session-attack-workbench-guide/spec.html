Full specification

Required behavior

  1. Test session fixation, forged token, copied expired token, two simultaneous logins, logout replay and revoked-session reuse against SQLite-backed state.
  2. Rotate identifiers after authentication and privilege changes, store only token digests, enforce absolute and idle expiry; academy idle timeout is 30 minutes and absolute timeout 8 hours.
  3. Cover CSRF on every unsafe route, including login, logout and upload when present; do not accept an XSS defense as a substitute for CSRF.
  4. Use escaped plain-text rendering, parameterized SQL and safe generic errors; add nosniff, Referrer-Policy same-origin, frame restrictions and a CSP appropriate to a server-rendered app without inline scripts.
  5. Private responses use Cache-Control no-store. Tests inspect body, headers, logs and state; credentials, raw tokens and private paths must not leak.
  6. Document dependency review, locked installs and secret configuration; base password hashing is reused and measured rather than replaced with reversible encryption.

Out of scope

Build this focused deliverable, not the complete forum. Features in the Level up chapter are optional and are not prerequisites unless the roadmap explicitly selects them. Do not replace a core learning task with a framework or finished service.

Use synthetic users and disposable test data during development. Keep a decision record when the brief allows a choice; the record must include an independently verifiable consequence.
