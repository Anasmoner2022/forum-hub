Before implementing anything, predict the “Comment notification” case: input B comments on A’s published post, result one unread notification for A. Then contrast it with “Recipient isolation”.

Keep the boundary visible

  • recordDomainEvent(db, event): Insert event inside the domain transaction with stable event ID.
  • dispatchEvents(db, limit = 100): Deliver a bounded batch idempotently.
  • listInbox(db, recipientId, page): Return only authorized recipient notifications.
  • markNotificationRead(db, recipientId, notificationId): Update only that recipient’s notification.
