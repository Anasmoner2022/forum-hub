Commands

node --version
npm install --package-lock-only
npm ci
npm start -- demo
npm test

The demo/serve adapters are TODO assignments in src/scenario.js. Once implemented, demo runs the documented cases; serve starts the HTTP adapter where relevant. npm test must finish with zero failures, zero skipped tests and zero TODO tests. Exact output text may differ, but statuses, data, boundaries and cleanup must match the table.

Independent review

  • Use a fresh temporary database and synthetic credentials for each integration scenario.
  • Await asynchronous calls, close servers/connections, and use an injected clock for expiry and rate-limit checks.
  • Exercise both success and the specified forbidden/failure paths; record persistent state after each.
  • Run the earlier preparation regression cases for any component reused or changed here.

Exit gate

  • All required cases pass and test scaffolds contain no remaining test.todo or skipped cases.
  • A peer reproduces the run using only your README.
  • You can explain an invariant and repair an intentionally introduced defect.
  • No secrets or real user data appear in the submitted fixtures, logs or repository.

Do not start the next forum assignment merely because time elapsed. Resolve a failed readiness gate in preparation first.
