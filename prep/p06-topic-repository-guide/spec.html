Full specification

Required behavior

  1. Create a topic with author, title, body and 1–5 distinct existing label IDs; either the topic and all links are committed or none are.
  2. Create a reply with author and topic IDs; reject missing parent, missing author, blank content and content longer than 5000 code points.
  3. Retrieve topic details with author display name, labels and replies in ascending creation order then ID.
  4. Use bound values for all user data; SQL keywords, column names and ordering must come from an allowlist.
  5. Return domain errors for missing objects and invalid fields; do not return database rows containing credentials or session values to a renderer.

Out of scope

Build this focused deliverable, not the complete forum. Features in the Level up chapter are optional and are not prerequisites unless the roadmap explicitly selects them. Do not replace a core learning task with a framework or finished service.

Use synthetic users and disposable test data during development. Keep a decision record when the brief allows a choice; the record must include an independently verifiable consequence.
