Step 3: Wire the redirect flow

Connect POST validation to creation and use a 303 after success.

Questions before writing

  1. Which input and trusted context enter this component of HTML Forms and Safe Rendering Board?
  2. Which persisted or visible invariant must remain true if this step fails?
  3. Preserve an invalid body safely.

Guided build

  1. Write a small acceptance example for wire the redirect flow using this project's verification table.
  2. Preserve an invalid body safely.
  3. Use an internal ID to form the Location header.
  4. Implement the smallest boundary that satisfies that example; keep core logic in your own module and record your chosen policy.

Self-check

Refreshing after a successful POST leaves the message count unchanged.

Evidence to keep

Keep the exact input, observed result and state/diagram evidence that make this self-check independently reviewable. If the result differs, trace the component before continuing.
