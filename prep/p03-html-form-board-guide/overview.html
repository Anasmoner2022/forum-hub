Overview

Build an in-memory message board using server-rendered HTML and native forms, including a hostile-text fixture that remains harmless.

Concrete deliverables

  • Accessible list, detail and create pages without browser frameworks
  • An HTML rendering helper with explicit text and URL contexts

Why build this?

The learner must make creation observable and defend the failure case “Missing item”. Reading alone does not prove those behaviors; the artifact and review evidence do.

Prerequisites

  • P02: HTTP Message and Bounded Body Lab

Reuse and what changes

  • P02: HTTP Message and Bounded Body Lab supplies tested contracts. Preserve those behaviors while building HTML Forms and Safe Rendering Board.

Time and team

Estimated 10 focused learner-hours, including reading, implementation and review. Each learner builds and explains the core; pairing and review are encouraged.
