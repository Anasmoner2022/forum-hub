Questions before writing

Guided build

  1. Write a small acceptance example for read and validate asynchronously using this project's verification table.
  2. Catch JSON syntax errors separately from missing-file errors.
  3. Try PORT=abc on paper before writing conversion code.

Self-check

A missing file and a malformed file must have different diagnostic messages and the same nonzero exit code.

Evidence to keep

Keep the exact input, observed result and state/diagram evidence that make this self-check independently reviewable. If the result differs, trace the component before continuing.
