Full specification

Required behavior

  1. Accept node src/run.js inspect fixtures/config.json; output JSON with appName, port and runtimeMajor.
  2. Validate appName as a nonempty string and port as an integer from 1 through 65535; never silently accept an invalid port.
  3. Read configuration asynchronously; missing file, invalid JSON and invalid fields produce a short stderr message and exit code 1.
  4. Use ES modules, explicit relative imports and package.json scripts; generate and commit package-lock.json, exclude node_modules and secrets.
  5. Teach promises, await, try/catch, Buffer versus UTF-8 text, environment values and npm install versus npm ci before using them elsewhere.
