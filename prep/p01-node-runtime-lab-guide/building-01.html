Step 1: Separate runtime from configuration

Write the CLI input contract and put parsing in a module that can be imported without running the CLI.

Questions before writing

  1. Which input and trusted context enter this component of Node Runtime and Package Lab?
  2. Which persisted or visible invariant must remain true if this step fails?
  3. Compare process.argv to the documented command.

Guided build

  1. Write a small acceptance example for separate runtime from configuration using this project's verification table.
  2. Compare process.argv to the documented command.
  3. Specify which value wins when PORT and the file disagree; use PORT when present.
  4. Implement the smallest boundary that satisfies that example; keep core logic in your own module and record your chosen policy.

Self-check

Import the module in a test: it must neither print nor open files at import time.

Evidence to keep

Keep the exact input, observed result and state/diagram evidence that make this self-check independently reviewable. If the result differs, trace the component before continuing.
