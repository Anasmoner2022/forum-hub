Full specification

Required behavior

  1. Implement fixed-window policies in this single-instance lab: login 5 attempts per normalized identifier and 20 per source IP per 60 seconds; authenticated writes 30 per member per 60 seconds.
  2. For upload-enabled apps, add 5 attempts per member per 60 seconds; reject limits before expensive hashing or decoding where possible.
  3. The first request opens the window; the exact expiry time begins a new window. A blocked attempt does not extend the window. Include Retry-After in seconds rounded up.
  4. Resolve caller keys from trusted session context and socket peer; ignore spoofed X-Forwarded-For unless a separately documented trusted proxy policy is installed.
  5. Bound active key storage to 10000 entries, expire stale entries and define safe capacity rejection; a full limiter cannot silently disable protection. Bound simultaneous scrypt jobs to a measured small maximum, default 1 in the lab.
  6. Document restart reset and single-instance assumptions. Shared enforcement for multiple replicas requires another preparation project and is not implied.

Out of scope

Build this focused deliverable, not the complete forum. Features in the Level up chapter are optional and are not prerequisites unless the roadmap explicitly selects them. Do not replace a core learning task with a framework or finished service.

Use synthetic users and disposable test data during development. Keep a decision record when the brief allows a choice; the record must include an independently verifiable consequence.
