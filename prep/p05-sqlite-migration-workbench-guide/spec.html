Full specification

Required behavior

  1. Use Node.js 24.15+ and node:sqlite DatabaseSync; explicitly enable foreign keys on each connection and verify they are active.
  2. Write and execute CREATE, INSERT and SELECT statements directly; use no ORM. Introduce INTEGER, TEXT, NULL, primary/foreign keys, UNIQUE and CHECK.
  3. Migration v1 creates the core tables; v2 adds a harmless optional topic summary. Record applied versions and checksums; a second run is a no-op.
  4. Run a migration atomically. A failed SQL statement rolls back both schema changes and migration history; never mark a failed version applied.
  5. Bound lock waits, close the connection, keep DB files out of source control, and prove data survives process restart. Read node:sqlite release-candidate status in the runtime policy.

Out of scope

Build this focused deliverable, not the complete forum. Features in the Level up chapter are optional and are not prerequisites unless the roadmap explicitly selects them. Do not replace a core learning task with a framework or finished service.

Use synthetic users and disposable test data during development. Keep a decision record when the brief allows a choice; the record must include an independently verifiable consequence.
