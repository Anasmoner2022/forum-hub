Overview

Turn your reviewed ERD into a real SQLite database with versioned migrations, repeatable seeds and visible constraint failures.

Concrete deliverables

  • A migration runner, ordered SQL files and a persistent database
  • A migration journal and constraint demonstration transcript

Why build this?

The learner must make fresh migration observable and defend the failure case “Changed migration”. Reading alone does not prove those behaviors; the artifact and review evidence do.

Prerequisites

  • P01: Node Runtime and Package Lab
  • P04: Community ERD and Relational Schema Design

Reuse and what changes

  • P01: Node Runtime and Package Lab supplies tested contracts. Preserve those behaviors while building SQLite Schema and Migration Workbench.
  • P04: Community ERD and Relational Schema Design supplies tested contracts. Preserve those behaviors while building SQLite Schema and Migration Workbench.

Time and team

Estimated 12 focused learner-hours, including reading, implementation and review. Each learner builds and explains the core; pairing and review are encouraged.
