Step 3: Clean every failed path

Track temp paths through abort, parser errors and CSRF rejection.

Questions before writing

  1. Which input and trusted context enter this component of Streaming Multipart Upload Gateway?
  2. Which persisted or visible invariant must remain true if this step fails?
  3. Make cleanup safe when called twice.

Guided build

  1. Write a small acceptance example for clean every failed path using this project's verification table.
  2. Make cleanup safe when called twice.
  3. The original filename may contain ../ and is still only untrusted metadata.
  4. Implement the smallest boundary that satisfies that example; keep core logic in your own module and record your chosen policy.

Self-check

Abort halfway through an upload and observe an empty temp directory.

Evidence to keep

Keep the exact input, observed result and state/diagram evidence that make this self-check independently reviewable. If the result differs, trace the component before continuing.
