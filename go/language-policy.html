Submission parity

  • Use the same behavioral, SQL, access-control and Docker acceptance requirements in either language.
  • Do not replace assessed core logic with a framework, ORM or hosted authentication product.
  • Use reviewed specialist libraries only after their matching preparation.
  • Changing language mid-track requires repeating the affected preparation and regression evidence.
