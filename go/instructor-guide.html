Instructor delivery and assessment

Go learning path. The required forum behavior matches the Node.js path; reading, commands, examples and unfinished code here use Go.

Teach the Go route through its own guide set and readiness evidence. Learners arriving from JavaScript start with the expanded P01 Go foundation rather than translating Node.js examples during F01.

Go cohort release checklist

  • Pilot all Go preparation gates with the stated entry skills and revise time estimates.
  • Pin a supported Go patch, CGO compiler, SQLite/scrypt/OAuth/OIDC modules and container images.
  • Rehearse Google/GitHub test applications, HTTPS trust, image worker constraints and native package builds.
  • Compile each unfinished starter, then verify that its placeholder behavior tests fail until completed.
  • Keep P21 optional until its reviewed SQLCipher build, key policy and recovery evidence pass.
  • Use the same forum behavior and assessment contract for both languages.

Readiness and assessment

Every learner demonstrates a focused artifact, failure paths, peer reproduction and an invariant explanation. For each forum assignment, assess required behavior (35%), integrity/access control (25%), verification/error handling (20%), operations/reproducibility (10%) and team understanding/maintenance (10%). Critical access or integrity failures block acceptance.

Team delivery

  • Use teams of 4–5 and rotate storage, HTTP/authentication, rendering, operations and verification ownership.
  • F01: week 1 contracts/accounts; week 2 communication; week 3 reactions/filters/errors; week 4 Docker, restore and audit.
  • Each one-week extension starts after its own prep gate and finishes with the full installed-feature regression suite.
  • For combined optional features, test callback/HTTPS, media/moderation, edited-post reapproval, notification deletion and activity privacy.

Maintenance

Edit curriculum/prep-go.mjs for Go-specific material and the shared source metadata for domain contracts. Rebuild and run the source/published checks. No Learning Hub catalog or progress record is modified.
