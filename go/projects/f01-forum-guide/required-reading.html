Mandatory

  • 01-edu: forum source subject. Forum objectives, authentication, reactions, filters and instructions. Compare the academy contract to the source.
  • Go: net/http. Handler; Server; Request.Context. Reuse the prepared Go HTTP boundary.
  • Go: testing. T.Run; Cleanup. Repeat all accepted Go preparation cases.
  • Go: Accessing databases. Opening a database handle; Executing SQL statements; Querying for data. Understand sql.DB, rows and error ownership.

  • Go: net/http. Cookie; SetCookie; Request.Cookie. Separate opaque browser cookies from server state.
  • Go: crypto/rand. Read. Create unpredictable session and CSRF values.
  • Go: Executing transactions. Executing transactions. Enforce one active session per user atomically.

  • Go: Data race detector. Usage; typical data races. Detect unsafe shared-memory access.
  • Go: Create a module. Compile and install the application. Build an executable with explicit module inputs.
  • go-sqlite3: installation, DSN and database/sql driver. CGO_ENABLED and C compiler requirements. Keep builder and runtime native compatibility explicit.
