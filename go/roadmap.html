Forum curriculum roadmap

Go learning path. The required forum behavior matches the Node.js path; reading, commands, examples and unfinished code here use Go.

Follow the Go preparation gates below, then build each forum assignment using Go. P01 introduces the language; all later code assumes those exercises and checks are complete.

Build in this order

Base forum: P01–P12 → F01

  1. P01: Go Language, Runtime and Module Lab
  2. P02: HTTP Message and Bounded Body Lab
  3. P03: HTML Forms and Safe Rendering Board
  4. P04: Community ERD and Relational Schema Design
  5. P05: SQLite Schema and Migration Workbench
  6. P06: Topic and Reply Repository
  7. P07: Reaction State Machine and Transactions
  8. P08: Feed Filters, Aggregates and Pagination
  9. P09: Registration and Password Hashing Vault
  10. P10: Session Cookies, Route Guards and CSRF
  11. P11: Failure Handling, Tests and Team Integration
  12. P12: Docker Images, Volumes and Restore Drill
  13. F01: Forum: Full Stack Community

Authentication: P13–P15 → F02

  1. P13: External API Client and Secret Handling
  2. P14: OAuth Authorization Code, State and PKCE Lab
  3. P15: Google OIDC, GitHub Identity and Account Linking
  4. F02: Forum Authentication: Google and GitHub SSO

Image upload: P16–P17 → F03

  1. P16: Streaming Multipart Upload Gateway
  2. P17: Decoded Image Validation and Asset Lifecycle
  3. F03: Forum Image Upload: Verified Media in Posts

Security: P18–P20; P21 only for encryption bonus → F04

  1. P18: HTTPS, Certificates and Container Configuration
  2. P19: Rate Limiting and Bounded Work
  3. P20: Session Attack and Browser Defense Workbench
  4. P21: Optional Live Database Encryption and Recovery Lab — optional encryption bonus only
  5. F04: Forum Security: HTTPS, Limits and Session Defense

Moderation: P22–P23 → F05

  1. P22: Roles, Ownership and Permission Matrix
  2. P23: Approval Queue, Role Requests, Reports and Categories
  3. F05: Forum Moderation: Roles and Review Workflows

Advanced features: P24–P26 → F06

  1. P24: Owned Editing, Deletion and Stale Update Conflicts
  2. P25: Transactional Events and Notification Inbox
  3. P26: Personal Activity Queries and Index Observatory
  4. F06: Forum Advanced Features: Notifications, Activity and Editing

Independent extensions

After F01, each optional extension can branch independently from the accepted base. Follow each project’s prerequisite links. P21 is needed only for the encryption bonus. When combining extensions, repeat all installed-feature regressions.

Time planning

Plan 296 core preparation learner-hours plus 16 optional P21 hours. P01 includes 20 hours for the Go Tour and runtime foundation; estimates need classroom piloting. The final assignment estimates add to nine weeks after readiness gates. Integration is additional work even when every individual skill is already prepared.

Readiness gate

  • Demonstrate the required artifact and all failure/boundary cases.
  • Keep Go tests deterministic and free of skipped required checks.
  • Prove native driver and container compatibility before F01.
  • Return to the smallest failing preparation component when a gate fails.
