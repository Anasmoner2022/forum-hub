server := httptest.NewTLSServer(handler)

Go implementation notes

  • Trace fixation, expiry, replay, role change, CSRF and open-redirect attempts before implementing each fixture.
  • Use a fake clock and persisted session rows, then combine concurrent requests with explicit synchronization and the race detector.
  • Inspect response headers and redacted diagnostics; test state changes and stored rows as well as status codes.
