Required reading

Mandatory

  • OWASP: Session Management. Session fixation; renewal after privilege changes; server-side token storage; expiration. Turn lifecycle assumptions into attack tests.
  • OWASP: Cross-Site Request Forgery Prevention. Synchronizer Token Pattern; origin checks. Exercise every unsafe route.
  • OWASP: Authorization. Validate permissions on every request. Retain server authority under hostile input.
  • Go: net/http. Cookie; SameSite; headers. Inspect what browsers actually receive.
  • Go: net/http/httptest. NewTLSServer; Client. Exercise trusted HTTPS clients without disabling verification.
  • Go: testing. T.Run; Cleanup. Run deterministic attack fixtures.

Reuse from earlier projects

  • P18: HTTPS, Certificates and Container Configuration
  • P19: Rate Limiting and Bounded Work
  • P10: Session Cookies, Route Guards and CSRF

Recommended

  • Go: Error handling and Go. Returning, wrapping and classifying errors. Keep failures observable.
  • Go: testing. T.Run and Cleanup. Check the contract without sharing test state.

Read the exact named sections before implementation. The Go Tour and official Go documentation provide the language route; shared SQL/design reading retains the same book sections as the Node.js preparation. Pin specialist dependencies through the cohort runtime policy before using them.
