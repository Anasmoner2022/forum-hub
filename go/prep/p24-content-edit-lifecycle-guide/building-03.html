Step 3: Integrate optional moderation policy

Use an explicit installed-feature policy to requeue published edits without requiring moderation for the standalone lab.

Questions before writing

  1. What enters this component of Owned Editing, Deletion and Stale Update Conflicts, and which fields are trusted?
  2. Which invariant survives a failure?
  3. Do not add new moderation concepts at the advanced capstone.

Guided build

  1. Write an independent acceptance example for integrate optional moderation policy.
  2. Do not add new moderation concepts at the advanced capstone.
  3. An edit withdrawing a post must also withdraw its asset visibility.
  4. Make the installed moderation policy explicit: the same validated edit remains published in base mode and becomes pending when moderation is installed.
  5. Implement the smallest typed boundary and record the policy you chose.

Self-check

The same edit remains published in base mode and becomes pending in moderation mode.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
