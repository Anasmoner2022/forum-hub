Full specification

Required behavior

  1. Authors may edit or delete their own posts and comments; an authenticated nonowner gets 403. Admin overrides apply only when the moderation extension is installed.
  2. Track integer version starting at 1; an edit requires expectedVersion and increments it on success. Stale writes return 409 without overwriting newer content.
  3. Reapply existing length/category validation. Use soft deletion: retained rows are marked deleted and all public reads hide them; do not leave publicly visible child comments under a deleted post.
  4. Define behavior for reactions, assets and notifications on deleted parents. Keep retained references private; public counts and filters exclude deleted content.
  5. When moderation is installed, editing published post content returns it to pending review and immediately withdraws public visibility. Without moderation, valid edits remain published.
  6. All mutations require session and CSRF; write a dependency table before choosing retention or cleanup. No undo or file replacement is required in this lab.

Out of scope

Implement this focused artifact or named forum assignment. Optional extras are not required. No ORM or framework may replace the assessed logic. Use synthetic data and keep real credentials out of source, fixtures and logs. The Go and Node.js paths have the same domain behavior; this path implements it using the prepared Go tools.
