Go and subject refresher

Model a versioned edit as a conditional mutation on persisted author, ID and version. A stale save is a conflict, not a successful no-op.

type EditInput struct {
    ExpectedVersion int64
    Title string
    Body string
}
// Actor comes from the session, not from this input.

Go implementation notes

  • Use typed edit inputs and a trusted actor; check current ownership and the expected version in the write boundary.
  • Write the retained/deleted child visibility table before the transaction; keep public queries consistent with it.
  • Make the installed moderation policy explicit: the same validated edit remains published in base mode and becomes pending when moderation is installed.

Project-specific trace

Predict “Owner edit”: author edits post at current version should produce content changes; version increments. Contrast it with “Moderated edit”.
