Persist intent before delivery. A single-instance Go drain command can deliver durable inbox notifications without introducing a WebSocket server or an unbounded background goroutine.

Go implementation notes

  • Create events only for meaningful committed changes; reuse P07 transition fixtures to exclude repeated same-state and clear actions.
  • Keep notification insertion and delivered-marker update in one sql.Tx with a unique event-recipient constraint and a batch limit of 100.
  • Resolve current recipient and target visibility; use httptest to attempt another member’s list/read action by changing IDs.
