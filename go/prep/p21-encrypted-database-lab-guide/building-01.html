Step 1: Build and verify the encrypted driver

Use a cohort-pinned Linux build with build-essential, libssl-dev and pkg-config for source compilation; retain required runtime libcrypto.

Questions before writing

  1. What enters this component of Optional Live Database Encryption and Recovery Lab, and which fields are trusted?
  2. Which invariant survives a failure?
  3. Install native dependencies in the target image and keep package-lock.json.

Guided build

  1. Write an independent acceptance example for build and verify the encrypted driver.
  2. Install native dependencies in the target image and keep package-lock.json.
  3. Treat Windows as a Docker host; the binding runs inside Linux.
  4. Build an isolated Linux CGO module with a reviewed SQLCipher driver and compiler. Do not import ordinary and encrypted drivers that register the same sqlite3 name into one executable.
  5. Implement the smallest typed boundary and record the policy you chose.

Self-check

The clean container reports a nonempty cipher_version and passes a create/insert/select contract test.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
