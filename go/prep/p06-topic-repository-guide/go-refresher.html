Go and subject refresher

Start a transaction, defer rollback, and use only tx methods until commit. Calling db.Exec inside the transaction can escape its connection and break atomicity.

tx, err := db.BeginTx(ctx, nil)
if err != nil { return err }
defer tx.Rollback()
// TODO: perform related writes through tx, check errors, then commit.

Go implementation notes

  • Define Go input and result structs from the specification; represent missing data explicitly rather than overloading zero IDs.
  • Use ExecContext/QueryContext placeholders; never interpolate submitted IDs or title text into SQL.
  • Close rows, check rows.Err, distinguish sql.ErrNoRows and verify a failed final label insert leaves no partial topic.
