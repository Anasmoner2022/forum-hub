Overview

Build a repository for creating and retrieving topics, replies and labels while making ownership and transaction boundaries explicit.

Concrete deliverables

  • Repository functions with parameterized SQL
  • An integration suite using disposable database files

Why build this?

Make the “Topic creation” case observable and demonstrate the failure or boundary case “Join multiplication”. A peer must reproduce the artifact, not just recognize an API name.

Prerequisites

  • P05: SQLite Schema and Migration Workbench

Reuse and what changes

  • P05: reuse its tested Go contracts; preserve their regression cases while adapting them to this project.

Time and team

Plan about 12 focused learner-hours including reading, building and peer review.
