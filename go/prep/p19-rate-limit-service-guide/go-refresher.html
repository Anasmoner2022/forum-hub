Go implementation notes

  • Use RemoteAddr as the default peer identity and only parse forwarding headers behind a documented trusted proxy.
  • Keep check/increment/reset atomic; use a fake clock and a start barrier to prove exactly the allowed concurrent requests succeed.
  • Bound map cardinality and eviction, use a semaphore for expensive hashes, and release permits on errors and cancellation.
