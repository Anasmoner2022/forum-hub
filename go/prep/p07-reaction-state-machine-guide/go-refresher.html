Go implementation notes

  • Use a typed reaction value and write all nine transitions before SQL.
  • Keep the target/member uniqueness constraint and execute changes on one sql.Tx; do not hold a transaction while calling external services.
  • Start competing requests with a barrier, wait for both, then read committed state; classify exhausted SQLite lock contention separately.
