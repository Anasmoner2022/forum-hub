Full specification

Required behavior

  1. Call only a configured allowlisted provider endpoint with net/http.Client. Send server-side credentials only to that trusted origin and constrain redirects.
  2. Use AbortSignal.timeout, check response.ok, bound response bytes to 256 KiB while streaming, and validate parsed response fields.
  3. The local fake provider exposes /profile, /slow, /bad-json and /unavailable; this lab owns these endpoints and uses only synthetic credentials.
  4. Map provider errors to controlled domain failures. Do not log authorization headers, tokens or full callback URLs.
  5. Inject fetch and endpoint configuration for deterministic tests; do not automatically retry authorization-code exchanges in later projects.

Out of scope

Implement this focused artifact or named forum assignment. Optional extras are not required. No ORM or framework may replace the assessed logic. Use synthetic data and keep real credentials out of source, fixtures and logs. The Go and Node.js paths have the same domain behavior; this path implements it using the prepared Go tools.
