Step 2: Bound and validate outbound work

Implement deadline, streaming byte bound, status and shape checks.

Questions before writing

  1. What enters this component of External API Client and Secret Handling, and which fields are trusted?
  2. Which invariant survives a failure?
  3. response.json alone does not cap downloaded bytes.

Guided build

  1. Write an independent acceptance example for bound and validate outbound work.
  2. response.json alone does not cap downloaded bytes.
  3. Do not use a user-controlled URL as an identity endpoint.
  4. Configure http.Client timeout and CheckRedirect; use context cancellation, close resp.Body, and reject a response that exceeds the byte budget.
  5. Implement the smallest typed boundary and record the policy you chose.

Self-check

A 500, timeout and invalid JSON each fail predictably without authenticating anyone.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
