Go and subject refresher

An http.Client should have an explicit timeout and redirect policy. Close response bodies, bound their bytes and validate the decoded provider shape before trusting it.

req, err := http.NewRequestWithContext(ctx, http.MethodGet, endpoint, nil)
if err != nil { return err }

Go implementation notes

  • Use httptest.NewServer for success, timeout, malformed JSON and redirect scenarios with synthetic credentials.
  • Configure http.Client timeout and CheckRedirect; use context cancellation, close resp.Body, and reject a response that exceeds the byte budget.
  • Keep secrets in server configuration; redact Authorization, tokens and code/state parameters from diagnostics.
