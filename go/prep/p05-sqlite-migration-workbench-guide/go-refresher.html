Go and subject refresher

sql.DB is a pool, not one connection. Foreign-key enforcement is per SQLite connection; configure it in the driver DSN and test a newly acquired connection. Teach CGO and the native compiler now.

db, err := sql.Open("sqlite3", dsn)
if err != nil { return err }
defer db.Close()
// PingContext confirms opening; sql.Open alone may not establish a connection.

Go implementation notes

  • Use database/sql with github.com/mattn/go-sqlite3 and a reviewed version in go.mod/go.sum; prove CGO_ENABLED=1 and a compiler work on your host or Linux container.
  • Keep immutable numbered migration files; use a transaction and record the schema version only after every statement succeeds.
  • Configure _foreign_keys=on and a bounded _busy_timeout in the driver DSN; verify them on each opened connection and test restart persistence.

Project-specific trace

Predict “Fresh migration”: empty data/lab.sqlite; migrate should produce v1 and v2 recorded once. Contrast it with “Changed migration”.
