Step 1: Execute the designed schema

Convert P04 constraints into SQL and verify enforcement, not just syntax.

Questions before writing

  1. What enters this component of SQLite Schema and Migration Workbench, and which fields are trusted?
  2. Which invariant survives a failure?
  3. Create parent relations before dependants.

Guided build

  1. Write an independent acceptance example for execute the designed schema.
  2. Create parent relations before dependants.
  3. Store timestamps in one documented unit.
  4. Use database/sql with github.com/mattn/go-sqlite3 and a reviewed version in go.mod/go.sum; prove CGO_ENABLED=1 and a compiler work on your host or Linux container.
  5. Implement the smallest typed boundary and record the policy you chose.

Self-check

An orphan reply fails on every connection, not only the migration connection.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
