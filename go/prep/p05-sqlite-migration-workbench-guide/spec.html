Full specification

Required behavior

  1. Use database/sql with a reviewed github.com/mattn/go-sqlite3 version. Prepare CGO/compiler setup; configure and verify foreign-key enforcement on every connection.
  2. Write and execute CREATE, INSERT and SELECT statements directly; use no ORM. Introduce INTEGER, TEXT, NULL, primary/foreign keys, UNIQUE and CHECK.
  3. Migration v1 creates the core tables; v2 adds a harmless optional topic summary. Record applied versions and checksums; a second run is a no-op.
  4. Run a migration atomically. A failed SQL statement rolls back both schema changes and migration history; never mark a failed version applied.
  5. Bound busy waits, close rows/connections, keep database files out of Git and prove data survives process restart. Demonstrate the same host/container driver behavior.

Out of scope

Implement this focused artifact or named forum assignment. Optional extras are not required. No ORM or framework may replace the assessed logic. Use synthetic data and keep real credentials out of source, fixtures and logs. The Go and Node.js paths have the same domain behavior; this path implements it using the prepared Go tools.
