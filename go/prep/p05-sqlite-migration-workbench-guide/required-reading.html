Required reading

Mandatory

  • SQLite: CREATE TABLE. CREATE TABLE: column and table constraints. Translate the schema into executable SQL.
  • SQLite: Foreign Key Support. Sections 2 and 4.3: enabling foreign keys; deletion actions. Make integrity enforcement explicit.
  • Go: Accessing databases. Opening a database handle; Executing SQL statements; Querying for data. Understand sql.DB, rows and error ownership.
  • go-sqlite3: installation, DSN and database/sql driver. Installation; CGO_ENABLED; DSN foreign keys and busy timeout. Prepare the actual driver and C compiler before repository work.

Reuse from earlier projects

  • P01: Go Language, Runtime and Module Lab
  • P04: Community ERD and Relational Schema Design

Recommended

  • Go: Error handling and Go. Returning, wrapping and classifying errors. Keep failures observable.
  • Go: testing. T.Run and Cleanup. Check the contract without sharing test state.

Read the exact named sections before implementation. The Go Tour and official Go documentation provide the language route; shared SQL/design reading retains the same book sections as the Node.js preparation. Pin specialist dependencies through the cohort runtime policy before using them.
