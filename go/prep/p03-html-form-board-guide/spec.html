Full specification

Required behavior

  1. GET /messages displays messages; GET /messages/new displays a labelled form; POST /messages accepts URL-encoded title and body; GET /messages/:id displays one item.
  2. Require title length 1–120 and body length 1–5000 Unicode code points after trimming. Invalid forms return 422 and preserve safe entered values.
  3. Successful creation redirects with 303 to the new detail page; refreshing the detail page must not create another message.
  4. Escape untrusted data in HTML text and quoted attributes; allow generated internal links only; render plain text rather than user HTML.
  5. Use headings, labels, fieldsets where needed, keyboard navigation, error text tied to fields and a meaningful empty state. Storage may reset on restart.
