Go and subject refresher

html/template escapes values for their HTML context. Pass typed page data to templates, keep submitted text as strings, and count Unicode code points rather than byte length.

type MessagePage struct {
    Title string
    Body string
    Errors map[string]string
}
// {{.Body}} is escaped by html/template; do not cast user input to template.HTML.

Go implementation notes

  • Use a bounded request body before ParseForm, and read r.PostForm so query parameters cannot override submitted fields.
  • Use utf8.RuneCountInString after trimming; render into a bytes.Buffer before sending headers so template failures can become a 500.
  • Use http.Redirect with http.StatusSeeOther after a successful mutation; reload the detail page to prove no duplicate write.

Project-specific trace

Predict “Creation”: POST title=Hello&body=World should produce 303; detail page shows Hello and World. Contrast it with “Missing item”.
