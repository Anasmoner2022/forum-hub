Go and subject refresher

A session cookie carries an opaque random token, while expiry, actor and role live on the server. Use an injected Clock function in tests instead of sleeping.

type Clock func() time.Time
type Session struct {
    UserID int64
    ExpiresAt time.Time
}
// The browser cannot supply trusted UserID or role fields.

Go implementation notes

  • Generate opaque tokens with crypto/rand, persist the prepared digest representation, and replace an earlier session atomically.
  • Use http.Cookie flags explicitly; test absolute and idle expiry using a fake clock and revoke by deleting the server record.
  • Implement CSRF and Origin checks as handlers/middleware before writes; compare tokens safely and reject cross-origin mutation attempts.

Project-specific trace

Predict “Valid login”: valid credentials in browser A should produce authenticated session; required cookie attributes. Contrast it with “CSRF”.
