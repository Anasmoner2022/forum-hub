Full specification

Required behavior

  1. POST /login verifies credentials and creates a fresh opaque 32-random-byte token; store only its SHA-256 digest with member ID, issued time and absolute expiry in SQLite.
  2. Successful login invalidates older sessions for that member atomically. Session expiry is 8 hours for this lab and is enforced server-side; injected clock enables deterministic tests.
  3. Cookie is HttpOnly, SameSite=Lax, Path=/ and Max-Age consistent with expiry; Secure is enabled in HTTPS mode. Local HTTP mode is documented and cannot masquerade as deployed security.
  4. POST /logout revokes the row and expires the cookie; missing, forged, expired or revoked tokens do not authenticate. Guests may read but cannot mutate.
  5. Use a synchronizer CSRF token tied to the server session plus an origin check on unsafe same-origin form requests. Reject missing/wrong CSRF with 403, including logout. Add a short-lived pre-login form session/token for login and registration CSRF protection.

Out of scope
