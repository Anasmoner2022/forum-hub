Level up: optional extensions

  1. Add an idle timeout alongside absolute expiry.
  2. Compare crypto.randomUUID with opaque random-byte identifiers; retain server-side state, digest storage and the same lifecycle checks.
  3. Add a session-device page while retaining one active login.
  4. Add privilege-change rotation.
  5. Design a remember-me token with its own revocation rules.

A new library or technology selected as a required extension needs its own completed preparation first. Extra features do not waive the base acceptance cases.
