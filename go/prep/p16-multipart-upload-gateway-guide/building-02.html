Step 2: Enforce streaming limits

Handle file, field, part and whole-request bounds with a bounded receive deadline.

Questions before writing

  1. What enters this component of Streaming Multipart Upload Gateway, and which fields are trusted?
  2. Which invariant survives a failure?
  3. The file stream’s truncated flag must never be ignored.

Guided build

  1. Write an independent acceptance example for enforce streaming limits.
  2. The file stream’s truncated flag must never be ignored.
  3. Use decimal bytes consistently in fixtures and error text.
  4. Wrap the whole body in MaxBytesReader and enforce fields<=8, field bytes<=16 KiB, one file, parts<=9 and the distinct file/request limits.
  5. Implement the smallest typed boundary and record the policy you chose.

Self-check

A 20,000,001-byte file fails during receipt, not after reading arbitrary extra bytes.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
