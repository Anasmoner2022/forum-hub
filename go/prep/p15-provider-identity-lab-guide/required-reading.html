Required reading

Mandatory

  • Google: OpenID Connect. Obtaining user information from the ID token; Validating an ID token; Discovery. Verify identity claims rather than only decode them.
  • GitHub: Authorizing OAuth apps. Web application flow. Configure real GitHub registration and login.
  • GitHub: REST API endpoints for emails. List email addresses for the authenticated user. Handle private or absent email.
  • go-oidc: OpenID Connect verification. Provider discovery; IDTokenVerifier; Verify; Claims. Verify Google ID tokens with a maintained verifier and configured trust.
  • Go: golang.org/x/oauth2. Config.Exchange; Token; authenticated client. Exchange codes and call the GitHub identity endpoints.

Reuse from earlier projects

  • P14: OAuth Authorization Code, State and PKCE Lab
  • P09: Registration and Password Hashing Vault

Recommended

  • Go: Error handling and Go. Returning, wrapping and classifying errors. Keep failures observable.
  • Go: testing. T.Run and Cleanup. Check the contract without sharing test state.

Read the exact named sections before implementation. The Go Tour and official Go documentation provide the language route; shared SQL/design reading retains the same book sections as the Node.js preparation. Pin specialist dependencies through the cohort runtime policy before using them.
