Step 3: Resolve accounts and link explicitly

Implement first-login onboarding, repeat login and reauthenticated linking.

Questions before writing

  1. What enters this component of Google OIDC, GitHub Identity and Account Linking, and which fields are trusted?
  2. Which invariant survives a failure?
  3. A matching email does not authorize taking an existing local account.

Guided build

  1. Write an independent acceptance example for resolve accounts and link explicitly.
  2. A matching email does not authorize taking an existing local account.
  3. Concurrent first logins must converge through unique constraints.
  4. Use the bounded oauth2 client for GitHub /user and verified-email lookup; never auto-link accounts by matching email alone.
  5. Implement the smallest typed boundary and record the policy you chose.

Self-check

A provider identity cannot be linked to two members even under competing requests.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
