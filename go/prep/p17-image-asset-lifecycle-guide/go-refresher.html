Go and subject refresher

JPEG, PNG and GIF decoders are registered through image/jpeg, image/png and image/gif. A small compressed file can expand into a large image; metadata checks and process resource limits are separate protections.

import (
    "image"
    _ "image/jpeg"
    _ "image/png"
    _ "image/gif"
)
// image.DecodeConfig is a preflight, not proof the entire image is valid.

Go implementation notes

  • Use DecodeConfig for preflight, then fully decode JPEG/PNG or all GIF frames inside a constrained worker process. Goroutine cancellation cannot stop a decoder that ignores context.
  • Before decoding, inspect GIF descriptors with bounded parsing to reject excess frames/aggregate pixels; the worker must also have a timeout and a container/OS memory limit.
  • Use opaque server-generated names, an explicit MIME allowlist and parent visibility checks; compensate stored-file writes when the database transaction fails.

Project-specific trace

Predict “Required formats”: valid JPEG, PNG and GIF including animation should produce all accepted with correct decoded types. Contrast it with “Database failure”.
