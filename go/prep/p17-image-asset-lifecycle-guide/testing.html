Commands

go version
go mod tidy
go fmt ./...
go vet ./...
go test ./...
go build ./cmd/lab
go run ./cmd/lab demo

Initially the run and tests fail with TODO diagnostics. The compile-only command go test -run "^$" ./... checks scaffold compilation; it does not run the required behavior tests. Replace every failing placeholder with independently specified assertions.

Independent review

  • Use t.TempDir and t.Cleanup so each integration case owns its database, files and server.
  • Use an injected clock and deterministic fixtures; join concurrent work before checking results.
  • Check responses, persistent state and cleanup on both success and failure.
  • Repeat the earlier Go preparation cases after adapting reused components.

Exit gate

  • All required behavior cases pass; no placeholder failures or skipped required tests remain.
  • A teammate reproduces the build, run and verification from your README.
  • Explain an invariant and repair an intentionally introduced defect.
  • No real secrets, user credentials or private data are included.
