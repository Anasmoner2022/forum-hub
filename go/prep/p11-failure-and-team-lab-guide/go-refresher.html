Go and subject refresher

A Go test must fail when its invariant is violated. Use t.TempDir and t.Cleanup, join worker goroutines before the test returns, and check returned errors rather than discarding them.

Go implementation notes

  • Separate error classification from HTTP translation; unexpected panics produce a generic 500 and a redacted server diagnostic.
  • Use table-driven tests, httptest.NewServer, t.TempDir and t.Cleanup. Wait for concurrent work before asserting; use channel results rather than Fatal from a helper goroutine.
  • Run go test ./..., go vet ./... and go test -race ./... on a supported CGO platform; include migration conflicts and a deliberately injected failure.
