Full specification

Required behavior

  1. Classify malformed input (400), unauthenticated (401), forbidden/CSRF (403), missing object (404), method mismatch (405), conflict (409), oversized body (413), unsupported type (415), validation (422), rate limit (429 later), unexpected fault (500) and temporary DB unavailability (503).
  2. Use testing and net/http/httptest, table-driven cases, t.TempDir/t.Cleanup, injected clocks and synchronized concurrent tests. Check all errors, join worker goroutines and run the race detector on a supported host.
  3. Inject a database error and renderer error; user responses must omit stack traces, SQL, paths and credentials; a sanitized log retains a request ID.
  4. Test domain modules independently and real HTTP+SQLite integration. Each test owns its database and closes connections and servers even after failure.
  5. Teams practise feature branches, review, one schema migration owner per change, a shared API contract and conflict resolution; each student explains and modifies a module they did not originally write.
