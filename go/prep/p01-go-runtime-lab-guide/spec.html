Full specification

Required behavior

  1. Accept go run ./cmd/lab inspect fixtures/config.json; output JSON with appName, port and runtimeMajor="go1.26".
  2. Validate appName as a nonempty string and port as an integer from 1 through 65535. PORT overrides the file only when present.
  3. Missing files, invalid JSON, invalid fields and read failures return classified errors; main prints one short diagnostic to stderr and exits 1.
  4. Use a Go module, typed configuration and an internal package. Commit go.mod and, when dependencies exist, go.sum. Keep files and secrets out of init functions.
  5. Complete the named Tour sections and exercises for slices/maps, pointers, structs, methods, interfaces, errors, defer, goroutines, channels, select and mutexes. Explain when a sequential function is sufficient before adding concurrency.

Out of scope

Implement this focused artifact or named forum assignment. Optional extras are not required. No ORM or framework may replace the assessed logic.
