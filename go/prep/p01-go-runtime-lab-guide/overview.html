Overview

Build a command-line workspace inspector that reads a configuration file, reports the runtime, and exits predictably when its inputs are wrong.

Concrete deliverables

  • A modular CLI with a JSON configuration file and reproducible module metadata
  • A setup record showing the same commands on two teammates’ machines

Why build this?

Make the “Valid file” case observable and demonstrate the failure or boundary case “Read failure”. A peer must reproduce the artifact, not just recognize an API name.

Prerequisites

Basic programming, HTML, terminal use and Git. Go syntax, modules, error handling and concurrency are introduced in P01; databases start in P04/P05.

Reuse and what changes

This entry lab introduces Go to learners with basic programming experience. Complete the named Tour exercises and module/error/concurrency checks before P02.

Time and team

Plan about 20 focused learner-hours including reading, building and peer review.
