Step 3: Make modules and tests reproducible

Format, compile and test the CLI, then have a teammate reproduce it.

Questions before writing

  1. What enters this component of Go Language, Runtime and Module Lab, and which fields are trusted?
  2. Which invariant survives a failure?
  3. A standard-library-only project does not need an invented dependency or go.sum.

Guided build

  1. Write an independent acceptance example for make modules and tests reproducible.
  2. A standard-library-only project does not need an invented dependency or go.sum.
  3. Use a small channel exercise to explain cancellation and a mutex exercise to explain the race detector before later server labs.
  4. Implement the smallest typed boundary and record the policy you chose.

Self-check

A clean copy runs go test ./..., go build ./cmd/lab and the documented inspect command with the same fixture result.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
