Go and subject refresher

Go functions return errors as values. Read JSON into a typed struct, validate fields and return an error; main owns stderr and the process exit code. Complete the Tour exercises first, including interfaces and concurrency.

type Config struct {
    AppName string `json:"appName"`
    Port int `json:"port"`
}
// json.Unmarshal(data, &cfg) decodes structure; domain validation is separate.

Go implementation notes

  • Put CLI argument handling in cmd/lab and reusable code in internal/lab. Use os.LookupEnv to distinguish an absent PORT from an empty PORT.
  • Use os.ReadFile, encoding/json and strconv; handle returned errors explicitly. Distinguish bytes, UTF-8 text, rune counts, zero values and invalid configuration.
  • Teach go.mod, module paths, imports, gofmt, go test, go build, defer, errors.Is, contexts and synchronization. Commit go.sum once external dependencies are introduced.

Project-specific trace

Predict “Valid file”: {"appName":"inspector","port":3000} should produce JSON includes appName=inspector, port=3000 and runtimeMajor="go1.26"; exit 0. Contrast it with “Read failure”.
