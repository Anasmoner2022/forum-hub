Level up: extra features

Level up: optional extensions

  1. Add a --help command with exact usage.
  2. Introduce a config schema version and reject unsupported versions.
  3. Add a dry-run report that redacts secret fields.
  4. Support a second configuration file with an explicit merge policy.

A new library or technology selected as a required extension needs its own completed preparation first. Extra features do not waive the base acceptance cases.
