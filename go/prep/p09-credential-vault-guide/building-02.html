Step 2: Implement a versioned hash record

Wrap asynchronous scrypt, generate salts and persist parameters with derived bytes.

Questions before writing

  1. What enters this component of Registration and Password Hashing Vault, and which fields are trusted?
  2. Which invariant survives a failure?
  3. Set maxmem consistently with the chosen work factor.

Guided build

  1. Write an independent acceptance example for implement a versioned hash record.
  2. Set maxmem consistently with the chosen work factor.
  3. Validate record lengths before timingSafeEqual.
  4. Use golang.org/x/crypto/scrypt, crypto/rand and crypto/subtle. Reject malformed parameters before allocating and derive with the trained work factors.
  5. Implement the smallest typed boundary and record the policy you chose.

Self-check

Two hashes of the same password differ while both verify.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
