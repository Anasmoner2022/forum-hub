Go and subject refresher

scrypt.Key returns a derived byte slice and an error. Bound record parameters before deriving; a goroutine alone is not a concurrency budget. Use a semaphore to cap simultaneous expensive work.

type HashRecord struct {
    Version int
    N, R, P int
    Salt []byte
    Digest []byte
}
// The record stores derivation parameters and a salt, never the original password.

Go implementation notes

  • Normalize the email before the unique insert and handle a concurrent uniqueness violation; never trust a precheck as the only guard.
  • Use golang.org/x/crypto/scrypt, crypto/rand and crypto/subtle. Reject malformed parameters before allocating and derive with the trained work factors.
  • Use a bounded semaphore around hashing, measure peak memory, release it on every path and return one generic invalid-credentials response.
