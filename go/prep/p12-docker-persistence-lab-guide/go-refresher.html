Go and subject refresher

A CGO SQLite binary may depend on the runtime C library. Build in a pinned Linux builder, run in a compatible runtime image and prove the final image starts as a non-root user.

# Container build outline, to complete in this lab:
# 1. Copy go.mod/go.sum and download reviewed modules.
# 2. Build with CGO_ENABLED=1 in a compiler-equipped builder.
# 3. Copy the executable into a compatible non-root runtime.

Go implementation notes

  • Use a multi-stage Go Dockerfile, install the native compiler in the builder and record the libc/architecture requirements of the runtime.
  • Mount data and uploads as owned volumes; use exec-form startup and http.Server.Shutdown for graceful termination.
  • Use SQLite backup or VACUUM INTO under the prepared procedure rather than copying a live WAL database file; prove restored rows and constraints.
