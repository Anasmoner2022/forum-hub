Step 2: Bind and consume login attempts

Implement TTL, browser binding and atomic one-time use.

Questions before writing

  1. What enters this component of OAuth Authorization Code, State and PKCE Lab, and which fields are trusted?
  2. Which invariant survives a failure?
  3. State lookup alone is insufficient when the browser cookie is not checked.

Guided build

  1. Write an independent acceptance example for bind and consume login attempts.
  2. State lookup alone is insufficient when the browser cookie is not checked.
  3. A provider failure does not make a consumed attempt reusable.
  4. Store a hashed browser-binding value, state, verifier and five-minute expiry; atomically consume the attempt using SQL before exchanging the code.
  5. Implement the smallest typed boundary and record the policy you chose.

Self-check

Two simultaneous callbacks with one state result in at most one exchange.

Evidence to keep

Keep exact input, result and state/diagram evidence. If the self-check fails, trace this component before moving on.
