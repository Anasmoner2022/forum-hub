Preparation → forum assignment roadmap

Start from basic JavaScript, HTML, terminal use and Git. Complete preparation in the numbered order below; each gate requires a working deliverable, concrete checks, peer reproduction and an individual explanation. Preparation time is additional to the assignment weeks.

  1. Base forum

    Complete P01–P12, then build F01.

    1. P01: Node Runtime and Package Lab (8 focused hours)
    2. P02: HTTP Message and Bounded Body Lab (10 focused hours)
    3. P03: HTML Forms and Safe Rendering Board (10 focused hours)
    4. P04: Community ERD and Relational Schema Design (12 focused hours)
    5. P05: SQLite Schema and Migration Workbench (12 focused hours)
    6. P06: Topic and Reply Repository (12 focused hours)
    7. P07: Reaction State Machine and Transactions (10 focused hours)
    8. P08: Feed Filters, Aggregates and Pagination (10 focused hours)
    9. P09: Registration and Password Hashing Vault (12 focused hours)
    10. P10: Session Cookies, Route Guards and CSRF (14 focused hours)
    11. P11: Failure Handling, Tests and Team Integration (12 focused hours)
    12. P12: Docker Images, Volumes and Restore Drill (12 focused hours)

    Then: F01: Forum: Full Stack Community (4 weeks, 4–5 students).

    Entry gate: reproduce the base forum preparation cases before combining them in the assignment. Each team member explains a boundary and repairs one introduced defect.

  2. Authentication

    Complete P13–P15, then build F02.

    1. P13: External API Client and Secret Handling (8 focused hours)
    2. P14: OAuth Authorization Code, State and PKCE Lab (12 focused hours)
    3. P15: Google OIDC, GitHub Identity and Account Linking (14 focused hours)

    Then: F02: Forum Authentication: Google and GitHub SSO (1 week, 4–5 students).

    Entry gate: reproduce the authentication preparation cases before combining them in the assignment. Each team member explains a boundary and repairs one introduced defect.

  3. Image upload

    Complete P16–P17, then build F03.

    1. P16: Streaming Multipart Upload Gateway (10 focused hours)
    2. P17: Decoded Image Validation and Asset Lifecycle (12 focused hours)

    Then: F03: Forum Image Upload: Verified Media in Posts (1 week, 4–5 students).

    Entry gate: reproduce the image upload preparation cases before combining them in the assignment. Each team member explains a boundary and repairs one introduced defect.

  4. Security

    Complete P18–P20; P21 only for encryption bonus, then build F04.

    1. P18: HTTPS, Certificates and Container Configuration (10 focused hours)
    2. P19: Rate Limiting and Bounded Work (10 focused hours)
    3. P20: Session Attack and Browser Defense Workbench (12 focused hours)
    4. P21: Optional Live Database Encryption and Recovery Lab — optional bonus gate (16 focused hours)

    Then: F04: Forum Security: HTTPS, Limits and Session Defense (1 week, 4–5 students).

    Entry gate: reproduce the security preparation cases before combining them in the assignment. Each team member explains a boundary and repairs one introduced defect.

  5. Moderation

    Complete P22–P23, then build F05.

    1. P22: Roles, Ownership and Permission Matrix (10 focused hours)
    2. P23: Approval Queue, Role Requests, Reports and Categories (14 focused hours)

    Then: F05: Forum Moderation: Roles and Review Workflows (1 week, 4–5 students).

    Entry gate: reproduce the moderation preparation cases before combining them in the assignment. Each team member explains a boundary and repairs one introduced defect.

  6. Advanced features

    Complete P24–P26, then build F06.

    1. P24: Owned Editing, Deletion and Stale Update Conflicts (12 focused hours)
    2. P25: Transactional Events and Notification Inbox (14 focused hours)
    3. P26: Personal Activity Queries and Index Observatory (12 focused hours)

    Then: F06: Forum Advanced Features: Notifications, Activity and Editing (1 week, 4–5 students).

    Entry gate: reproduce the advanced features preparation cases before combining them in the assignment. Each team member explains a boundary and repairs one introduced defect.

Which assignments are mandatory?

F01 is mandatory. F02–F06 remain optional. The sequence above is the recommended full-track order, not a rule that an optional extension depends on every earlier optional extension. A team taking only moderation can complete F01, P22–P23 and F05. Follow each project’s explicit prerequisite links and their transitive dependencies.

For the cumulative full track, keep one repository and add extensions in this order. After every extension, run all installed-feature tests. For independent assessment, branch from the accepted F01 baseline and keep conditional policies disabled unless their extension is installed. P24 teaches the conditional moderation adapter; choose its moderation-mode check only when P22/P23 and F05 are included.

Time planning

284 estimated preparation learner-hours, plus 16 hours if P21 is selected. These are planning estimates, not promises: reading and review are included, and a pilot cohort may need more. At 40 focused hours/week, preparation is about 7.1 weeks; at 20 it is about 14.2 weeks. All six assignment estimates add to 9 weeks (4 + 5×1), producing roughly 17 full-time weeks before optional P21 and contingency. Do not compress the whole preparation track into the original four-week forum build.

Readiness recovery

If a learner fails a gate, repeat the smallest failing prep component and its verification rather than introducing the missing concept inside the final assignment. Existing skill can satisfy a gate through demonstrated evidence; attendance alone cannot.

Optional technology changes

Real-time SSE/WebSocket transport, additional SSO providers, rich text, multi-instance storage/limits and extra media formats are not silently required. Their Level up references require a new completed preparation deliverable if selected as academy requirements.
