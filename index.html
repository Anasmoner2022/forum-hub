MADE FOR BUILDING

More than a reading list

Each guide includes exact reading, a focused refresher, a full specification, downloadable TODO scaffolds, guided build chapters, concrete verification, engineering questions and optional extensions. The student supplies the implementation or design.

BEFORE YOU START

Bring the basics

Start with basic JavaScript, HTML, terminal use and Git. Node.js and database concepts are taught here. The guided route uses Node.js; teams can choose Node.js or Go under the same behavioral contract. One preparation project is an optional encryption lab.

This is your standalone forum curriculum. All guides stay in this folder; the Learning Hub catalog and student progress are unchanged.
