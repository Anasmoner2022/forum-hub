Runtime, dependencies and launch preflight

The worked route targets a cohort-pinned Node.js 24 LTS patch at or above 24.15.0, with ES modules. This workspace has Node 24.19.0 and the core SQLite import was checked. Do not switch to a floating latest runtime during the cohort.

node:sqlite is marked release candidate in the reviewed Node 24 documentation, not fully stable. The synchronous DatabaseSync API is used for small single-instance educational workloads. Keep transactions short, avoid awaiting external I/O inside them, and do not infer multi-replica or production-scale guarantees. A driver substitution requires repeating repository and Docker prep gates.

Dependency installation in student implementations

npm install --save-exact jose
npm install --save-exact busboy sharp
# Optional P21 only, inside its reviewed Linux build environment:
npm install --save-exact @journeyapps/sqlcipher
# After recording reviewed versions and committing the lockfile:
npm ci

The teacher resolves and tests exact cohort versions before release; these commands intentionally do not claim an untested universal version set. Do not install all specialist dependencies in P01. The curriculum itself requires no third-party package to build or read.

Configuration worksheet

  • APP_HOST/PORT and public origin; local HTTP versus HTTPS mode.
  • DB_PATH, uploads/temp directories, migration status and named volume ownership.
  • SESSION absolute/idle TTL and injected test clock.
  • Provider client IDs, secrets and exact callback URIs; test-user approval where required.
  • TLS certificate/key paths and explicit development trust.
  • Password work factors, memory budget and concurrency cap.
  • Limiter policies, trusted socket/proxy assumptions and bounded key capacity.
  • Optional SQLCipher key mount, driver build target, cipher version and recovery custodian.

Launch checks the academy must perform

The guides and their unfinished scaffolds are curriculum artifacts; they are not completed student implementations. Before the first cohort, a mentor should pilot the preparation, rehearse the external-provider setup and native packages, measure the time estimates, and validate the runtime/container matrix. The supplied instructor guide includes a release checklist.
