Choose Node.js or Go as a team

A team of 4–5 students chooses one backend for the shared forum repository: JavaScript on Node.js or Go. The choice applies consistently to the base and its extensions. The behavioral contract and assessment are the same. These guided chapters teach the Node.js route. Go teams must satisfy the equivalent preparation checks before starting and already know Go syntax, modules, errors and its standard library.

Node route: core node:http/node:https, node:sqlite, node:crypto, node:test and semantic HTML. No frontend frameworks or ORM; Busboy, Sharp and jose are allowed for prepared specialist tasks. Go route: net/http, html/template, database/sql with an approved SQLite driver, crypto/rand, a reviewed password-hash package and testing. See the language policy for exact package and readiness rules.

Decision record

  • Choose one backend before starting F01, record why and identify the teammates maintaining it.
  • Keep the chosen language through its optional extensions unless the academy approves a planned migration with repeated prep checks.
  • Use the same HTTP behavior, SQLite schema requirements, access control, UI restrictions and acceptance evidence for either language.
  • The generated guide pages and starter code use Node.js; Go submissions are valid implementations of the same assignments, not separate parallel worked guides.
  • A Go team completes equivalent prep deliverables in Go or demonstrates them before its capstone, including package/container compatibility. The academy verifies language fluency before allowing Go to bypass the Node worked route.

Academy package policy

Do not use backend scaffolding frameworks, an ORM or an authentication-as-a-service product to replace the core assessed skills. Specialist parsing/decoding/cryptographic verification libraries are allowed because those are prepared boundaries, not the domain logic. Pin reviewed dependencies for the cohort, commit a lockfile/go.sum and recheck native builds in Docker. No frontend framework is allowed.

Differences from 01-edu

The supplied source briefs are Go-oriented and list Go packages. This academy adaptation explicitly admits Node.js and its documented specialist dependencies. Password hashing, ERD submission, CSRF and concrete verification are baseline academy requirements even where the source called them bonuses or recommendations.
