Overview

Harden the running forum using the prepared certificate, rate-limit, password and server-session defenses, then demonstrate them under hostile and concurrent requests.

Concrete deliverables

  • HTTPS Docker configuration and route-limit policy
  • Threat model, attack regression suite and certificate/secret operations procedure

Why build this?

The learner must make https observable and defend the failure case “Regression”. Reading alone does not prove those behaviors; the artifact and review evidence do.

Prerequisites

  • F01: Forum: Full Stack Community
  • P18: HTTPS, Certificates and Container Configuration
  • P19: Rate Limiting and Bounded Work
  • P20: Session Attack and Browser Defense Workbench

Reuse and what changes

  • P18: HTTPS, Certificates and Container Configuration supplies tested contracts. Preserve those behaviors while building Forum Security: HTTPS, Limits and Session Defense.
  • P19: Rate Limiting and Bounded Work supplies tested contracts. Preserve those behaviors while building Forum Security: HTTPS, Limits and Session Defense.
  • P20: Session Attack and Browser Defense Workbench supplies tested contracts. Preserve those behaviors while building Forum Security: HTTPS, Limits and Session Defense.

Time and team

Optional assignment, 1 week, team of 4–5. This time begins after readiness review; preparation is additional.

A team of 4–5 students chooses one backend for the shared forum repository: JavaScript on Node.js or Go. The choice applies consistently to the base and its extensions. The behavioral contract and assessment are the same. These guided chapters teach the Node.js route. Go teams must satisfy the equivalent preparation checks before starting and already know Go syntax, modules, errors and its standard library.

Node route: core node:http/node:https, node:sqlite, node:crypto, node:test and semantic HTML. No frontend frameworks or ORM; Busboy, Sharp and jose are allowed for prepared specialist tasks. Go route: net/http, html/template, database/sql with an approved SQLite driver, crypto/rand, a reviewed password-hash package and testing. See the language policy for exact package and readiness rules.
