Required reading

Mandatory

  • OWASP: Transport Layer Security. Certificates and TLS protocol versions. Reuse P18 configuration and operations reasoning.
  • OWASP: Session Management. Session renewal, storage and expiration. Reuse P20 attack workbench.
  • OWASP: Password Storage. scrypt work factors. Keep measured expensive-work budgets.

Reuse from earlier projects

  • F01: Forum: Full Stack Community
  • P18: HTTPS, Certificates and Container Configuration
  • P19: Rate Limiting and Bounded Work
  • P20: Session Attack and Browser Defense Workbench

Reuse the earlier tested behavior and contracts. Refactor names or adapters only where this specification requires it; rerun the earlier checks after adaptation. A final forum assignment introduces no new required Node.js technology.

Recommended

  • Eloquent JavaScript, fourth edition, chapter 8: Bugs and Errors: exceptions and cleanup, to make failures observable.
  • Node.js 24: Test runner: running tests and hooks, to repeat verification independently.

Book references use Eloquent JavaScript fourth edition and Fundamentals of Database Systems seventh edition. Only the named sections are needed; the specialist official documentation supplies material not covered by the books.
