Wiring it up and running it

Keep imports free of side effects. src/run.js is the supplied CLI boundary; complete src/scenario.js to assemble the prepared modules, load only synthetic fixtures and expose the documented demo or server mode. The supplied wrapper handles a rejected scenario without printing internal stacks.

Run procedure

node --version
npm install --package-lock-only
npm ci
npm start -- demo
npm test
# After wiring the HTTP adapter, start it in one terminal:
npm start -- serve
# In another terminal, use curl.exe on Windows (curl on Linux/macOS):
curl.exe -i http://localhost:3000/health
# After completing Docker configuration:
docker compose build
docker compose up -d
docker compose logs
# Retain the named test-data volume:
docker compose down

Environment and dependencies

Use the cohort-pinned Node 24.15+ patch and matching container runtime. See runtime-policy.html from the curriculum index for allowed packages, RC API limitations, provider setup and native-build prerequisites. Create directories before writing fixture files; never use the forum guide folder as a production data directory.
