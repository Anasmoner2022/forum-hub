Required reading

Mandatory

  • 01-edu: forum source subject. Forum objectives, authentication, reactions, filters and instructions. Compare the academy contract to the source.
  • Eloquent JavaScript, fourth edition, chapter 20: Node.js. HTTP servers; Streams. Review the already-built Node server components.
  • Node.js 24: SQLite. DatabaseSync and StatementSync. Reuse P05/P06 storage contracts.

Reuse from earlier projects

  • P01: Node Runtime and Package Lab
  • P02: HTTP Message and Bounded Body Lab
  • P03: HTML Forms and Safe Rendering Board
  • P04: Community ERD and Relational Schema Design
  • P05: SQLite Schema and Migration Workbench
  • P06: Topic and Reply Repository
  • P07: Reaction State Machine and Transactions
  • P08: Feed Filters, Aggregates and Pagination
  • P09: Registration and Password Hashing Vault
  • P10: Session Cookies, Route Guards and CSRF
  • P11: Failure Handling, Tests and Team Integration
  • P12: Docker Images, Volumes and Restore Drill

Reuse the earlier tested behavior and contracts. Refactor names or adapters only where this specification requires it; rerun the earlier checks after adaptation. A final forum assignment introduces no new required Node.js technology.

Recommended

  • Eloquent JavaScript, fourth edition, chapter 8: Bugs and Errors: exceptions and cleanup, to make failures observable.
  • Node.js 24: Test runner: running tests and hooks, to repeat verification independently.

Book references use Eloquent JavaScript fourth edition and Fundamentals of Database Systems seventh edition. Only the named sections are needed; the specialist official documentation supplies material not covered by the books.
